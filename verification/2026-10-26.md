## Repeatable commands

Run from the relevant package with its independent dependencies installed:

```sh
# apps/agent-bridge
./node_modules/.bin/bun test
./node_modules/.bin/tsc --noEmit
./node_modules/.bin/bun run build
./node_modules/.bin/bun run smoke
./node_modules/.bin/bun run smoke:render
./node_modules/.bin/bun run smoke:approval
./node_modules/.bin/bun run smoke:production
./node_modules/.bin/bun run smoke:review
./node_modules/.bin/bun run smoke:editorial

# apps/web
./node_modules/.bin/vitest run
./node_modules/.bin/tsc --noEmit
../agent-bridge/node_modules/.bin/bun run build
```

`smoke:editorial` creates its own synthetic fixture, tests the full edited-plan
HTTP/render/export lifecycle, stops its server, and deletes its temporary media.

## Remaining limits

- Transcript selections use complete caption cues, not invented word timestamps.
  A cut through a cue omits that cue and requests caption regeneration.
- Protection applies to one proposal; it must be selected again after saving.
- Shortening keeps the earliest available footage plus explicitly protected
  passages. It does not claim semantic highlight ranking.
- Filler suggestions only flag standalone filler cues. Mixed speech and ambiguous
  phrases remain intact. Quiet audio may contain speech and must be reviewed.
- Timeline edits replace crossfades with midpoint hard cuts and retime/trim
  production layers. The proposal warns before applying either change.
- Restore previous revision creates a new revision from the immediately preceding
  snapshot; it is not a multi-step undo-stack browser.
- Review proposals expire after 30 minutes or a bridge restart. Saved revisions
  persist. Pause analysis supports 40 clips / 10 source minutes with a 45 s budget.
- No external transcription-provider upload, native desktop run, native Editor API
  synchronization, public deployment, or social publication was performed.
