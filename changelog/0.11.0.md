# Local fork milestone: bridge 0.11.0

26 October 2026. This records delivered fork development, not a public upstream
release or GitHub release/tag announcement.

## Main workspace

- Persistent local projects home and stable main-project links.
- Full-video editor with a visible timeline, split, proposed trim/remove/reorder,
  transcript editing, revision saves and restore.
- Video append, image/video watermarks, ducked music, supplied SRT/VTT captions,
  titles and production-layer removal; detailed settings in Advanced.
- Independent child clip reviews from saved main ranges.
- Full-timeline preview/final requests up to four hours; oversized finals fail
  instead of silently exporting a five-minute excerpt.
- Final playback/download/package, editable copies, parent snapshot locks,
  restart recovery and atomic successful output publication.
- Long-caption movie composition above 40 cues and caption QA up to 10,000 cues,
  subject to text/body limits; the old 200-cue burn-in cap is removed.
- `opencut-studio`, strict ports and coordinated service shutdown.

## Review and editorial work included in this milestone

- Choose clips → Edit → Review & export; concise cards with rationale, source
  beside transcript and an explicit Source/Edited preview switch.
- Plain save labels, secondary batch controls and Advanced production/history.
- Local transcript proposals, protected passages, cleanup/pause suggestions,
  separate saves, caption/layer retiming and revision restoration.
- Existing preview/final approval and v1/v2 compatibility preserved.
