# Local fork milestone 0.12.0 — 27 October 2026

Main-project Shorten now accepts longer targets up to four hours and starts with a
valid default. Single session previews/finals show preparation, encoding progress,
elapsed time and cancellation; reopening reconnects to the job. Friendly errors
retain technical details and an explicit retry path. Preview and final approvals
remain separate.

macOS Browse chooses source/video, watermark, audio and caption paths without
copying/uploading. Create/Add stays explicit and the media-root boundary applies.
Manual paths remain available.

Validated with 75 bridge and 30 web tests, both typechecks/builds, generated-media
HTTP/browser checks and existing main/editorial/review smokes. See the
[dated verification](../verification/2026-10-27-reliability.md) for exact evidence
and limits. This is a private local fork milestone, not an upstream public release.
